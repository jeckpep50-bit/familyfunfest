# Family Fun Fest 2026 · Registro de asistentes

Sitio público del registro de asistentes de Eight Academy.

- `index.html`: página para familias y panel de coordinación. Configura `API_URL` y `GOOGLE_CLIENT_ID` en el bloque `FFF_CONFIG`.
- `hero.jpg`: imagen del evento.

El backend (Google Apps Script + Google Sheets) y la nómina **no** están en este repositorio a propósito: contienen datos personales de estudiantes.
